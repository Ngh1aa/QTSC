# QTSC Page Redesign UX Execution

## Applied UX skill routing

Selected approach:
- website-audit-and-redesign
- journey-driven-content-and-layout
- visual-design-direction
- ui-craft-and-visual-qa
- information-architecture

The project keeps static HTML/CSS/JS architecture.

## Business goal

QTSC website is not only an information portal. It should become a digital ecosystem gateway connecting:

- enterprises looking for workspace
- technology companies looking for ecosystem visibility
- investors looking for opportunities
- partners looking for cooperation
- visitors looking for campus information

## User intent model

### Enterprise tenant
Need:
- available workspace
- infrastructure capability
- ecosystem benefits
- contact pathway

CTA:
Explore space → Schedule consultation

### Investor
Need:
- investment advantages
- policy support
- ecosystem proof

CTA:
Discover investment opportunities

### Technology buyer
Need:
- solution providers
- marketplace
- technology capability

CTA:
Find solutions

### Community / visitor
Need:
- campus story
- innovation activities
- events

CTA:
Explore QTSC campus

## Page transformation rules

Every page follows:

1. Context hero
- clear purpose
- one primary CTA
- one proof point

2. Decision support content
- reduce reading
- increase comparison
- show evidence

3. Ecosystem connection
- link users to next logical journey

4. Conversion ending
- relevant CTA instead of generic contact

## Design system rules

Brand:
- QTSC red as action color
- white primary canvas
- dark sections only for premium technology storytelling

Layout:
- editorial enterprise style
- strong whitespace
- large typography
- proof driven sections

Components:
- ecosystem cards
- trust metrics
- decision cards
- timeline
- capability modules
- CTA panels

UX laws applied:
- Hick's Law: reduce choices by grouping user goals
- Miller's Law: keep information chunks controlled
- Jakob's Law: familiar enterprise navigation patterns
- Fitts's Law: clear CTA targets
- Progressive Disclosure: reveal detail after intent selection

## QA checklist

- User can understand QTSC value within first screen
- Every business audience has a clear path
- CTA hierarchy is consistent
- Components are reusable
- Mobile journey remains task-first
