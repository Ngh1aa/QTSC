# QTSC Website Redesign Phase 2

## Goal

Transform QTSC from an information website into a digital ecosystem platform connecting:

- Technology enterprises
- Investors
- Partners
- Innovation communities

## UX Principles

### Intent-first navigation

Homepage prioritizes user goals instead of internal organization.

Primary journeys:

1. Find office and infrastructure
2. Explore investment opportunities
3. Find technology partners
4. Discover ecosystem activities

## Homepage Experience

Recommended order:

1. Hero + user intent selector
2. Trust metrics
3. Ecosystem capability
4. Business journey
5. Proof / case studies
6. Contact conversion

## Component Direction

- Intent cards
- Ecosystem map
- Business stepper
- Enterprise directory
- Infrastructure showcase
- Investor pathway

## Design Direction

Premium Gov-Tech / Smart City Ecosystem

Keywords:

- Trust
- Scale
- Innovation
- Connectivity
- Future infrastructure
