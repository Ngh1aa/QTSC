# QTSC Visual Direction — Connected Tech Campus

## Visual thesis

**Architectural + Editorial + Technology.** The site should feel like a credible physical technology campus with a living business network—not a government portal, generic corporate template or futuristic AI/SaaS product.

## Signature language

- **Q-Grid:** an architectural 4/12-column grid, strong rails and aligned section edges.
- **Orange Signal:** QTSC orange `#EE4623` is limited to actions, active states, connection nodes and material proof.
- **Connected Nodes:** restrained rings, dots and grid lines appear only at signature moments such as Hero and final handoff.
- **Real Campus:** official architecture, infrastructure, people and ecosystem imagery is preferred over generic code/server stock.

## Composition rules

| Layer | Rule |
|---|---|
| Page silhouette | Full-width hero, intent dock, editorial proof rail, asymmetric capability list, immersive campus, dark decision field, current signals, final connection field |
| Container | Maximum 1320px; shared vertical/grid alignment across routes |
| Rhythm | 80px mobile; 104–124px tablet/desktop for primary sections |
| Typography | Manrope; large medium-weight display; compact uppercase metadata; body line length around 60–75 characters |
| Color | White and soft neutral dominate; charcoal creates one decision field; orange uses roughly 5–10% of the visible interface |
| Borders | Structural 1px rails, not shadow-based floating cards |
| Radius | 6–10px controls; 16px only for large modules; no excessive rounded-card repetition |
| Motion | Entry/orientation and feedback only; no motion required to understand or operate the page |

## Photography

1. Campus and recognisable architecture.
2. Digital infrastructure and labs.
3. Businesses, partners and people in real QTSC contexts.
4. Innovation, education, community and green/smart operations.

Use stable aspect ratios, local scrims when text overlays a photo, and explicit dimensions to reduce layout shift.

## Do / don't

**Do**

- Use real evidence and source/date context.
- Let content roles produce different compositions.
- Use the orange signal to mark the next action.
- Preserve readable Vietnamese diacritics and natural line breaks.

**Don't**

- Repeat centred heading + three rounded cards.
- Use purple/cyan/neon/rainbow gradients.
- Add glass, glow or shadows to ordinary content.
- Treat every section as a brand moment.
- Use generic AI, server-room or code imagery when an official QTSC photograph fits.

## Composition proof

- **Home:** narrative routing surface with five task launchers and seven primary blocks.
- **Evaluation pages:** utility hero + criteria/evidence + contextual handoff, capped at seven blocks.
- **Directory/Marketplace:** search/filter working surface before editorial storytelling.
