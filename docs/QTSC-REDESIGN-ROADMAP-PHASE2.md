# QTSC Redesign Roadmap Phase 2

## Objective

Upgrade QTSC website into a digital ecosystem platform for enterprises, investors, technology partners and communities.

## User journeys

### Enterprise
Homepage -> Office & Infrastructure -> Building Detail -> Contact

### Investor
Homepage -> Investment -> Advantages -> Policy -> Connect

### Technology partner
Homepage -> Company Directory -> Marketplace -> Partner Contact

### Community
Homepage -> Innovation -> Events -> Community

## Design direction

- Premium enterprise technology ecosystem
- White space focused
- QTSC orange/red as action color
- Dark sections for trust and authority
- Image-first storytelling

## UX rules

- Homepage starts from user intent
- Reduce choices using Hick's Law
- Follow familiar enterprise website patterns
- Keep one primary CTA per section
- Progressive disclosure for deep information

## Components

- Mega navigation
- Intent cards
- Ecosystem map
- Directory filters
- Infrastructure showcase
- Investment timeline
- Case study cards
