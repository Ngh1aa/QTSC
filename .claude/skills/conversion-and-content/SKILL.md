# Conversion & Content

## Goal

Mọi block phải giúp user **hiểu → tin → quyết định → hành động**, không tồn tại chỉ để trang dài/đẹp.

## Inputs

- Audience/JTBD + barriers.
- Journey/decision criteria.
- Page role trong IA.
- Brand voice.
- Primary conversion goal và secondary actions.

## Workflow

1. Define page job: user đến để biết/làm gì?
2. Write one clear value proposition + proof strategy.
3. Build information hierarchy: answer main question sớm, progressive detail sau.
4. Define CTA hierarchy: one dominant action per decision context.
5. Place trust/proof sát claim/decision thay vì gom hết cuối page.
6. Handle common objections bằng evidence/content phù hợp.
7. Write interface microcopy cho form/loading/empty/error/success.
8. Define content fields/constraints nếu CMS/reuse cần.
9. Review scannability, mobile density và accessibility of language.
10. Coordinate SEO intent mà không làm copy robotic/keyword-stuffed.

## Decision rules

- Specific outcome > vague marketing adjective.
- Evidence > self-praise.
- CTA mô tả action/result > “Click here/Submit”.
- Không fabricate testimonial/logo/stat.
- Không dùng false urgency/scarcity.
- Ít chữ nghĩa là **compression**, không phải xóa proof/context cần thiết.
- Error copy phải giúp recovery.

## Output

- Page content hierarchy.
- CTA/trust/objection map.
- Content model khi cần.
- UI state copy.

## Acceptance criteria

- Above-fold trả lời site/page là gì + cho ai + next action.
- Page có primary action phù hợp decision stage.
- Claims quan trọng có proof strategy.
- Copy phản ánh brand voice, không generic AI prose.
- Empty/error/loading/success copy theo scope.
- Mobile scan không bị wall of text.
- SEO intent được đáp ứng tự nhiên.

## Anti-patterns

- Mỗi section title kiểu “Empowering excellence”.
- Nhiều CTA ngang cấp cạnh tranh nhau.
- Fake numbers/logos/reviews.
- Copy kể về công ty quá lâu trước khi nói user nhận gì.
- SEO keyword lặp làm hỏng readability.
